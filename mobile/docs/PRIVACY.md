# 隐私说明（个人项目 / 侧载）

本说明面向自行编译或接受 APK 侧载的用户，**不是**应用商店法务文本。

## 数据存在哪

- 订阅、文章、全文、AI 摘要、阅读进度：本机 **sql.js 库**（经 IndexedDB 持久化）  
- 大模型 API Key：本机 **Capacitor Preferences**  
- **无账号、无云同步、不连接作者服务器**（除非你配置的 RSS / LLM 地址）  

## 会访问网络的情况

- 刷新订阅、抓取全文、加载图片/视频  
- 调用你配置的 LLM 服务（文章内容会发往该服务商）  
- 可选：B 站/YouTube 等公开接口用于视频元信息  

卸载应用即删除本地库（以系统行为为准）。

## 权限

| 权限 | 用途 |
|------|------|
| 网络 | 抓取与 AI |
| 通知 | 后台刷新进度与完成提醒（可关） |
| 前台服务（dataSync） | 后台抓取时短暂保活并显示进度 |
| 存储/文档（经 Filesystem） | 导出备份 |

## 备份文件

导出的 sqlite / OPML / 诊断 JSON 可能含标题与正文摘要，请自行保管，勿发到公开渠道。
