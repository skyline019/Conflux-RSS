# 演示脚本（约 30～90 秒）

适合作品集录屏或面试口述。

## 准备

- 已装 Release APK，订阅里有几条可读源  
-（可选）已配置 LLM，便于演示流式摘要  
- 关闭勿扰，通知权限已开（若演示通知可另说）  

## 30 秒版

1. **打开 App** → 落在「今日」，指一下未读分组与刷新。  
2. **点开一篇** → 快速下滑展示正文/配图。  
3. **点「生成结构化摘要」**（或已有 AI 卡）→ 强调流式输出。  
4. **点分享** → 系统分享面板。  
5. 收尾一句：「数据只在手机本地，不连我的服务器。」  

## 90 秒版（加深度）

在 30 秒基础上增加：

- 侧栏打开「订阅广场」一瞥预设源  
- 设置里指一下「API Key 在 Preferences」「备份导出」  
- 返回键：阅读器 → 今日，再按才退出  
-（可选）飞行模式打开已抓全文，展示离线可读  

## 口述要点（技术）

- Capacitor + 共享 Web UI  
- fetch 拦截实现本地 API，sql.js 持久化  
- 签名 Release、默认 HTTPS  

## 避免

- 不要演示未配置 LLM 时狂点 AI（易失败打断节奏）  
- 可提一句「WorkManager 静默刷新 + 通知进度」；勿承诺秒级常驻后台（系统最短约 15 分钟）
