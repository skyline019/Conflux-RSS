# 用户指南（Android）

面向安装了汇阅 APK 的日常使用。数据仅存本机，不登录、不同步云端。

## 安装

1. 获取 `conflux-*-release.apk`（自行编译或作者分发）  
2. 允许「未知来源」安装  
3. 首次打开会看到「正在准备本地阅读库…」，稍后进入 **今日**  

覆盖升级：安装更高 `versionCode` 的同包名 APK，本地库一般保留。

## 今日

- 按订阅源分组展示未读  
- 失败源会提示  
- 右上角「刷新全部」抓取最新  

侧栏可进入：全部文章、未读、视频流、星标、事件、规则、归档、统计、设置。

## 阅读

- 点文章进入阅读器；返回键 / 「← 列表」回到列表或今日  
- **分享**：系统分享标题 + 摘要要点 + 链接  
- **原文**：应用内浏览器打开  
- **抓全文 / AI 总结 / 提问**：工具栏与文内 AI 面板（需在设置启用大模型）  
- 滚动位置会记住，列表可能显示「未读完」  

## 订阅

侧栏「订阅广场」：

- 从预设目录批量添加  
- 粘贴 RSS / 网站 URL 自动发现  
- 导入 OPML  

系统分享链接到汇阅，或打开 `conflux://add?url=...`，会打开订阅并尽量预填地址。

## 大模型（可选）

设置 →「大模型接入」：

1. 选服务商或自定义 OpenAI 兼容 Base URL  
2. 填模型名与 API Key（Key 存在系统 Preferences，不进本地库明文）  
3. 「测试连接」→「保存全部设置」  
4. 阅读页生成结构化摘要或提问  

不启用时仍可用本地抽取式摘要等能力（效果较弱）。

## 全量刷新速度

设置 →「全文抓取」：

- **全量刷新源并发**（默认 **8** 路，可调 1–16）  
- **全文抓取并发**（单源内深抓文章，默认 3）  

第二次及以后刷新会尽量走 HTTP 304：源未变则跳过下载/解析。部分源不返回 ETag 时仍会完整抓取。

## 自动刷新与通知

设置 →「手机端 · 日常与备份」：

- **后台静默刷新间隔**（系统 WorkManager，最短约 15 分钟）  
- 仅 Wi‑Fi 时刷新  
- 完成后通知（需授予通知权限）  

刷新时通知栏显示进度（如 `3/12 · 某源 +2`），结束后显示新增篇数或失败摘要。

### 后台抓取：机型差异与兜底

| 现象 | 说明 / 怎么做 |
|------|----------------|
| 偶发闪一下界面 | 冷启动需短暂拉起 WebView；进程已在时可软唤醒，多数情况不再闪屏 |
| 通知停在「点按通知以继续」 | 部分系统禁止后台拉起 Activity：点一下进度通知即可继续抓取 |
| 到点不刷新 | 在系统设置允许汇阅「后台运行 / 忽略电池优化」；仍受 WorkManager 最短约 15 分钟限制 |
| 杀进程后 | 开机后会重新调度；勿强制结束汇阅若依赖静默刷新 |

## 备份与恢复

同一设置分区：

| 操作 | 说明 |
|------|------|
| 导出备份 | 本地库文件 + OPML 到文档目录 |
| 导入备份/OPML | `.sqlite` 整库替换，或 OPML 合并订阅（同 URL 跳过） |
| 导出诊断 | schema 版本、最近抓取日志等 JSON |

换机建议：先导出备份，新机安装后导入。

## 离线

无网时顶栏提示离线；已抓取全文的文章仍可阅读。刷新、抓新文、调用 LLM 需要网络。

## 常见问题

**刷新很慢 / 部分源失败**  
源站限流或规则变更属正常；今日页会标失败源，可稍后重试。可适当提高「全量刷新源并发」，过高可能被源站限流。

**后台通知有了但文章没变**  
先点进度/完成通知确认抓取跑完；再打开 App 看「今日」。若仍无更新，检查 Wi‑Fi-only 与通知权限。

**AI 不可用**  
检查是否启用、Key、Base URL；Ollama 需本机或局域网可达（明文仅允许 localhost 等）。

**升级后丢数据**  
少见；若发生，用此前导出的备份恢复。卸载 App 会清空本地库。
