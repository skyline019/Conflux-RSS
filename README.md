# 汇阅 · Conflux RSS（桌面 Electron 分支）

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)

本分支面向 **桌面 Electron** 壳（`desktop/`）。  
**手机端请看默认分支 [`main`](https://github.com/skyline019/Conflux-RSS/tree/main)。**

## 与 main 的关系

| 分支 | 定位 |
|------|------|
| `main` | Android / Capacitor（主交付） |
| `web` | Next.js 网页 + Postgres |
| `desktop`（当前） | Electron 桌面 |

## 快速开始

```bash
cd desktop
npm install
npm start
```

打包产物默认在 `desktop/release/`（已 gitignore）。
